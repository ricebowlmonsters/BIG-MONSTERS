Analisis Pelanggan Google Maps

Pantau suara pelanggan, temukan masalah yang berulang, dan ubah temuan menjadi tindakan perbaikan.

Belum ada sinkronisasi. API Google Business Profile harus dipanggil dari backend agar kredensial tidak tersimpan di browser.
Cara mengisi dan menggunakan sinkronisasi
  1. Buka profil bisnis di Google Maps, pilih Bagikan, lalu salin link profil dan tempel ke kolom Link profil Google Maps.
  2. Kolom Endpoint sinkronisasi backend diisi URL server milik aplikasi yang sudah terhubung ke Google Business Profile API, misalnya https://domain-anda/api/google-reviews.
  3. Buat project Google Apps Script baru, tempel file backend khusus Google Maps, lalu buka Project Settings → Script Properties dan tambahkan GBP_ACCOUNT_ID serta GBP_LOCATION_ID.
  4. Deploy sebagai Web app, salin URL deployment, lalu tambahkan ?action=getGoogleReviews di belakangnya untuk diisi pada kolom endpoint.
  5. Pastikan endpoint mengembalikan JSON berupa array ulasan atau format {"reviews": []}, kemudian klik Sinkronkan Ulasan.
  6. Jika belum memiliki backend Google Business Profile API, kosongkan endpoint dan gunakan Impor CSV untuk memasukkan data ulasan secara manual.

Link Google Maps berfungsi sebagai identitas profil. Link tersebut tidak dapat mengambil ulasan secara langsung dari browser tanpa backend dan kredensial Google yang sah.
